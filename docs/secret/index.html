广雅应用

先简单写一个从广雅应用到百度的超级无敌保姆级教程吧。首先你需要一个知乎账号（重要），等广雅应用上来之后打开广雅应用（见 图：打开广雅应用）。

图：打开广雅应用

打开后，找到这个问卷（见 图：问卷），问卷下面有很多个链接，找到“DeepSeek”打开（见 图：打开Deepseek）。

图：问卷

图：打开Deepseek

进去之后，滑到最底下，可以看到有一个知乎的图标，点开它即可跳转到知乎（见 图：跳转到知乎）。

图：跳转到知乎

进入知乎，登录你的账号（一般来说是不用验证码的），然后进行搜索，输入 baidu.com，点击第一个结果，然后就可以去到百度了（呜呜呜～终于好了）。

图：搜索百度

图：进入第一个结果

顺带提一嘴，如果上了广雅应用，你想要导出你的平板拍的视频，你可以搜索 pan.moe 进入萌盘，登录你提前在家注册好的账号，就能上传视频了（见 图：搜索萌盘）。

图：搜索萌盘
