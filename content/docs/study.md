## 关于分科

相信很多高一新入学的学生都对自己高一下的选科、分科有很多疑惑。

## 打印在读证明

在读证明有很大的用处，可以向 Jetbrains 申请学生优惠和一些学生免费，也可以去广州大剧院半价看戏。打印在读证明比较方便的方式为自行打印，有两台机可以打印：一楼书吧和四楼高三书吧。高三书吧的打印机如下图（[图：打印机](#fig-prove1)）。

<a id="fig-prove1"></a>
![打印机](/pics/prove/prove1.jpg)

*打印机*

<a id="fig-prove2"></a>
![打印机屏幕](/pics/prove/prove2.jpg)

*打印机屏幕*

我们可以点击右上角的“登录”来登录你的账号。什么？你不知道自己的账号是什么？没关系，点开后的登录方式选择“账号密码”，如 [图：选择登录方式](#fig-prove3)。然后填写你的学号和身份证后6位，如 [图：填写学号和身份证后6位](#fig-prove4)。不出意外，没被别人改过得话，点击“登录”按钮就可以登录了。

<a id="fig-prove3"></a>
![选择登录方式](/pics/prove/prove3.jpg)

*选择登录方式*

<a id="fig-prove4"></a>
![填写学号和身份证后6位](/pics/prove/prove4.jpg)

*填写学号和身份证后6位*

然后，你就可以点击主页顶部菜单栏的“业务办理”，点击“中文成绩证明”，稍作等待，就能看到你的成绩证明了。

<a id="fig-prove56"></a>
![业务办理](/pics/prove/prove5.jpg)
![中文成绩证明](/pics/prove/prove6.jpg)

*图：业务办理与中文成绩证明*

然后，点击右边蓝色的打印机形状的按钮，就可以打印了，如 [图：打印成绩证明](#fig-prove7)。每个学生可以免费打印10次。

<a id="fig-prove7"></a>
![打印成绩证明](/pics/prove/prove7.jpg)

*图：打印成绩证明*

拿到打出来的纸质版成绩证明，就可以拿去尽情使用了。
